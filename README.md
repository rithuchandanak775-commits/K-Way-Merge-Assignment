# K-Way-Merge-Assignment
K-way merge using Min Heap and Pairwise Merging

## Introduction

Merging combines multiple sorted lists into a single sorted list while maintaining the order of the elements.
This work compares k-way merging using a Min Heap with pairwise merging in terms of operations, time complexity, and space requirements.

## Input

Three sorted lists are used:

- L1 = 10, 30, 50, 70
- L2 = 20, 40, 60, 80
- L3 = 15, 35, 55, 75

## Methods

1. K-way Merge Using Min Heap
2. Pairwise Merging

## Final Output

10, 15, 20, 30, 35, 40, 50, 55, 60, 70, 75, 80
